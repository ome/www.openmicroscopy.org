Synopsis

Potential XSS vulnerability in OMERO.web when giving 'show' argument

Background

OMERO.web copies some URL query parameters into JavaScript variables inside an inline script without properly escaping the user provided values, providing a vector for executing code within another user's browser session.

For a successful exploit, a user must click a malicious link using a browser that does not automatically escape the problematic characters; all major modern browsers are automatically escaping the characters and thereby preventing this attack.

Affected Packages

OMERO.web <=5.33.3

Impact

Moderate severity.

Resolution

All OMERO.web deployments should be upgraded to at least 5.33.4.
