Today we are releasing OMERO.web 5.32.0, which includes improvements to the tag image count indicators and 
image paging, and the display of external info in the right-hand panel
in addition to other bugfixes and backend improvements.

Please see the [OMERO.web release](https://github.com/ome/omero-web/releases/tag/v5.32.0)
and [notes on upgrading](https://github.com/ome/omero-web/blob/v5.32.0/UPGRADING.md).

### Installing the Software

OMERO.web 5.32.0 is available from PyPI - see 
[here](https://pypi.org/project/omero-web/5.32.0/).

Official Docker images are available as usual on Docker Hub with either
the latest or the 5.32.0 tag:

* <https://hub.docker.com/r/openmicroscopy/omero-web-standalone>
* <https://hub.docker.com/r/openmicroscopy/omero-web>

Please note that the Docker images are now based on [Rocky Linux 9](https://rockylinux.org/) to
support the latest OMERO.web releases.

You are invited to discuss this announcement on
[the image.sc forum](https://forum.image.sc/tags/c/data-management/29/omero).

All the best with your upgrades,

The OME Team
