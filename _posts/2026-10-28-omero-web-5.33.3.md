On October 28, we released OMERO.web 5.33.3, which includes a bug fix for annotations 
without namespace and a fix for a security vulnerability, see 
[GHSA-pc58-q9c8-wh7j](https://github.com/ome/omero-web/security/advisories/GHSA-pc58-q9c8-wh7j)
for more details.

Please see the [OMERO.web release](https://github.com/ome/omero-web/releases/tag/v5.33.3)
and [notes on upgrading](https://github.com/ome/omero-web/blob/v5.33.3/UPGRADING.md).


### Installing the Software

OMERO.web 5.33.3 is available from PyPI - see 
[here](https://pypi.org/project/omero-web/5.33.3/).

Following the [security incident affecting eMudhra intermediate certificates](https://emudhra.we-have-a-problem.com/),
we strongly recommend to upgrade the versions of `pip` and `certifi` in the virtual environment running 
OMERO.web before upgrading `omero-web`. Please refer to this
[post on the Python forum](https://discuss.python.org/t/information-for-python-users-regarding-emudhra-emsign-ca-certificate-security-incident/109576)
for specific instructions on how to upgrade these packages safely.

Official Docker images are available as usual on Docker Hub with either
the latest or the 5.33.3 tag:

* <https://hub.docker.com/r/openmicroscopy/omero-web-standalone>
* <https://hub.docker.com/r/openmicroscopy/omero-web>

Please note that the Docker images are now based on [Rocky Linux 9](https://rockylinux.org/) to
support the latest OMERO.web releases.

You are invited to discuss this announcement on
[the image.sc forum](https://forum.image.sc/tags/c/data-management/29/omero).

All the best with your upgrades,

The OME Team
